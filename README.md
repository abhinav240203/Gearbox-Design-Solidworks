# Gearbox Design - SolidWorks

## Overview

This project contains the CAD design of a **multi-stage spur gear reduction gearbox** created using SolidWorks.

The gearbox uses multiple spur gear stages to reduce rotational speed and increase output torque.

## Gearbox Type

**Multi-Stage Spur Gear Reduction Gearbox**

## Features

- Spur gear transmission system
- Input and output shafts
- Multiple reduction stages
- Custom gearbox housing
- Bearing-supported shafts
- Complete SolidWorks assembly design

## Components

- Gearbox Housing
- Spur Gears
- Input Shaft
- Output Shaft
- Intermediate Shafts
- Ball Bearings

## Software Used

- SOLIDWORKS
